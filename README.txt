# Flowernett Florist Website

## Cara ganti foto
Semua foto ada di folder `images`.

- Foto utama: `images/hero.jpg`
- Foto toko: `images/toko.jpg`
- Produk: `images/products/buket-1.jpg` sampai `buket-4.jpg`
- Galeri: `images/gallery/foto-1.jpg` sampai `foto-6.jpg`

**Paling gampang:** ganti file foto dengan nama file yang sama. Tidak perlu mengubah HTML.

Contoh:
1. Siapkan foto bouquet baru.
2. Rename menjadi `buket-1.jpg`.
3. Timpa file lama di `images/products/`.
4. Upload ulang folder website ke hosting.

## Kalau mau tambah foto
Salin salah satu kartu produk atau baris galeri di `index.html`, lalu ubah nama file dan judulnya.

## Cara online gratis
Pilihan mudah: GitHub Pages, Netlify, atau Cloudflare Pages.
Website ini berupa HTML/CSS/JS statis, jadi tidak membutuhkan database atau hosting berbayar.

## Yang perlu kamu ubah sebelum online
- Nomor WhatsApp di `index.html`
- Link Instagram
- Nama/harga produk
- Cerita tentang toko
- Alamat dan jam buka
